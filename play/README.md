# Aset Google Play / toko aplikasi

File di folder ini siap diunggah ke Google Play Console (atau toko aplikasi lain).

| File | Ukuran | Fungsi |
|---|---|---|
| `ic_launcher-512.png` | 512×512 | Ikon aplikasi Play Store |
| `feature-graphic.png` | 1024×500 | Feature graphic |
| `screenshot-phone-1..4.png` | 1080×1920 | Screenshot ponsel |
| `screenshot-tablet-1..2.png` | 1920×1200 | Screenshot tablet 7″ |
| `screenshot-tv-1..2.png` | 1920×1080 | Screenshot Android TV |
| `promo-graphic.png` | 1280×720 | Promo graphic (opsional) |

Sumber ikon utama ada di [`assets/app-icon.png`](../assets/app-icon.png); versi mipmap Android otomatis dibuat dari file tersebut di `androidApp/src/main/res/mipmap-*`.
